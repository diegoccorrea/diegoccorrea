## 💿 About me

- 🔨 Specialized in **Paper / Spigot plugin development**.
- 🎮 Building tools for **any kind of Minecraft experience**.

## 💾 My open-source projects

| Plugin | Description |
|--------|-------------|
| [**polaris-duels**](https://github.com/diegoccorrea/polaris-duels) | Flexible and feature-rich duels plugin designed to stay as close to the vanilla experience as possible.
| [**polaris-uhc**](https://github.com/diegoccorrea/polaris-uhc) | Feature-rich UHC plugin with 200+ scenarios, match records system, moderation tools and extensive customization.
| [**shield-patterns**](https://github.com/diegoccorrea/shield-patterns) | Lightweight plugin that lets players create and apply custom banner patterns to their shield via an in-game GUI.
| [**mcdev-utils**](https://github.com/diegoccorrea/mcdev-utils) | General-purpose Paper utility library for item building, message formatting, world creation and more.
| [**woof-quests**](https://github.com/diegoccorrea/woof-quests) | Quest system focused on hardcore progression without armor and gradual difficulty increase.
| [**bucketreachfix**](https://github.com/diegoccorrea/bucketreachfix) | Lightweight patch that reverts the bucket reach bug-fix on 1.20.5 (MC-260889). Fixes ViaVersion bucket desync.
| [**miscolegio**](https://github.com/diegoccorrea/miscolegio) | Round-based quiz event plugin for Paper/Spigot 1.21+ with category levels (Kinder → University), wildcards, lives system, and automatic player elimination.
| [**player-hide**](https://github.com/diegoccorrea/player-hide) | Paper 1.21+ plugin that anonymizes all players during events — replacing their skins and usernames with unique colored profiles.

If you like my open-source projects, consider supporting me on [Ko-fi](https://ko-fi.com/diegoccorrea)! It's completely optional though :)
